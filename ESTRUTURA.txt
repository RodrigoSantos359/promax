COMO NAVEGAR O PROJETO
═══════════════════════════════════════════════════════════════════════

Para ENTENDER a arquitetura:
  1. Leia: ARQUITETURA.md
  2. Estude: src/automation/base.py
  3. Explore: src/automation/executor.py

Para IMPLEMENTAR uma rotina:
  1. Copie: routine_template.py
  2. Renomeie para: routine_XX_XX_XX.py
  3. Edite a classe: Implemente execute()
  4. Registre: Em src/automation/__init__.py

Para USAR a interface:
  1. Execute: python main.py --web
  2. Abra: http://localhost:5000
  3. Crie empresa, automação, execute

Para ESTENDER o framework:
  1. Implemente: scheduler.py com APScheduler
  2. Adicione: Múltiplos browsers
  3. Crie: Testes com pytest
  4. Faça: Deploy com Docker
